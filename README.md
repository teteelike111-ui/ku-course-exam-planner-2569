# KU Course & Exam Planner

เว็บไซต์สำหรับวางแผนตารางเรียนและตรวจสอบวันสอบของมหาวิทยาลัยเกษตรศาสตร์ (ภาคปลาย 2569)

## เปิดใช้งาน

- เปิดไฟล์ `index.html` โดยตรงในเบราว์เซอร์
- หรือเปิดผ่าน GitHub Pages หลังจากเปิดใช้งาน Pages ใน repository

## ฟีเจอร์

- เพิ่มรายวิชาแบบคัดลอกจาก my.ku.th
- เลือกหมู่เรียนและตรวจสอบชนกันของเวลาเรียน
- ตรวจสอบวันสอบกลางภาค / ปลายภาค
- บันทึกข้อมูลไว้ใน LocalStorage
- ส่งออก/นำเข้า JSON

## โฟลเดอร์

- `index.html` : หน้าเว็บไซต์หลัก
